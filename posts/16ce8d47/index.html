题目：求

I=∬D(x−ca+y−cb)dx dyI = \iint_D \left(\sqrt{\frac{x - c}{a}} + \sqrt{\frac{y - c}{b}}\right)\mathrm{d}x\,\mathrm{d}y I=∬D​(ax−c​​+by−c​​)dxdy

其中 DDD 由曲线 x−ca+y−cb=1\sqrt{\dfrac{x - c}{a}} + \sqrt{\dfrac{y - c}{b}} = 1ax−c​​+by−c​​=1 及直线 x=cx = cx=c，y=cy = cy=c 所围成（a,b,c>0a, b, c > 0a,b,c>0）。

对于二重积分的计算，识别出积分区域是十分重要的。那么对这道题来说，区域长什么样子呢？

区域

相比识别区域的关键就是看出 x−ca+y−cb=1\sqrt{\dfrac{x - c}{a}} + \sqrt{\dfrac{y - c}{b}} = 1ax−c​​+by−c​​=1 长什么样子，但这个东西乍一眼很难看出来，我们注意到，其中的 a,b,ca, b, ca,b,c 都是参数，可以想象到它们只是对图像进行了一些伸缩和平移。那我们就可以先不看它们，稍后再处理这些参数。拿掉它们后，我们先观察 x+y=1\sqrt{x} + \sqrt{y} = 1x​+y​=1。经过一些代点和对称性分析，可以想象它是一条在第一象限，过 (0,1)(0, 1)(0,1) 和 (1,0)(1, 0)(1,0)，关于 y=xy = xy=x 对称的一条向下弯曲的曲线。

实际上如果对 xa+ya=1x^a + y^a = 1xa+ya=1（a>0a > 0a>0）的样貌有一些感受，你会发现过 (0,1)(0, 1)(0,1) 和 (1,0)(1, 0)(1,0) 是铆钉这条曲线的两个端点，aaa 从 000 不断增大时这条曲线从向下凸逐渐转变为向上凸，a=1a = 1a=1 时就是一条直线，而 a=3a = 3a=3 时就是小米新 Logo 的轮廓（右上方）。

那我们现在回到 x−ca+y−cb=1\sqrt{\dfrac{x - c}{a}} + \sqrt{\dfrac{y - c}{b}} = 1ax−c​​+by−c​​=1，可以发现，ccc 控制这条曲线在 y=xy = xy=x 方向上平移，aaa 和 bbb 控制这两个端点在 x=cx = cx=c，y=cy = cy=c 上移动，总的来说就是 x+y=1\sqrt{x} + \sqrt{y} = 1x​+y​=1 平移与拉伸。而曲线 x−ca+y−cb=1\sqrt{\dfrac{x - c}{a}} + \sqrt{\dfrac{y - c}{b}} = 1ax−c​​+by−c​​=1 及直线 x=cx = cx=c，y=cy = cy=c 所围成的区域就是一个斜边向下凸的直角三角形。

换元

对这个区域进行积分，尤其是被积函数还是 x−ca+y−cb\sqrt{\dfrac{x - c}{a}} + \sqrt{\dfrac{y - c}{b}}ax−c​​+by−c​​，可想而知有多么庞大的工作量。对于这种情况来讲，换元是很有必要的一种操作手段。对于这种两个比较对称的部分相加等于一个定值的情况，三角换元是一个很可行的手段。于是我们为了凑成 cos⁡2θ+sin⁡2θ=1\cos^2\theta + \sin^2\theta = 1cos2θ+sin2θ=1，不妨设 x=c+akcos⁡4θx = c + ak\cos^4\thetax=c+akcos4θ，y=c+bksin⁡4θy = c + bk\sin^4\thetay=c+bksin4θ，但是这样仅仅只能表达那一条曲线，边界条件要怎么写呢？

我们注意到，对于在 x+y=1\sqrt{x} + \sqrt{y} = 1x​+y​=1 下方的点有 x+y<1\sqrt{x} + \sqrt{y} < 1x​+y​<1，那么很容易想到对于曲线 x+y=k\sqrt{x} + \sqrt{y} = kx​+y​=k，使 kkk 在 000 到 111 之间变化，它将扫过整个图形，这给我们一个启示，我们可以设 x=c+akcos⁡4θx = c + ak\cos^4\thetax=c+akcos4θ，y=c+bksin⁡4θy = c + bk\sin^4\thetay=c+bksin4θ，这样我们就可以写出积分区域的边界条件 0<k<10 < k < 10<k<1，0<θ<π20 < \theta < \dfrac{\pi}{2}0<θ<2π​，那么我们的积分就好做多了。

计算

换元过后，计算对应的 Jacobi 行列式

J=∣∂(x,y)∂(k,θ)∣=4abksin⁡3θcos⁡5θ+4abksin⁡5θcos⁡3θ=4abksin⁡3θcos⁡3θJ = \left|\frac{\partial(x, y)}{\partial(k, \theta)}\right| = 4abk\sin^3\theta\cos^5\theta + 4abk\sin^5\theta\cos^3\theta = 4abk\sin^3\theta\cos^3\theta J=​∂(k,θ)∂(x,y)​​=4abksin3θcos5θ+4abksin5θcos3θ=4abksin3θcos3θ

那么

I=∬D(x−ca+y−cb)dx dy=∫0π2dθ∫01k⋅4abksin⁡3θcos⁡3θ dkI = \iint_D \left(\sqrt{\frac{x - c}{a}} + \sqrt{\frac{y - c}{b}}\right)\mathrm{d}x\,\mathrm{d}y = \int_0^{\frac{\pi}{2}} \mathrm{d}\theta \int_0^1 \sqrt{k} \cdot 4abk\sin^3\theta\cos^3\theta\,\mathrm{d}k I=∬D​(ax−c​​+by−c​​)dxdy=∫02π​​dθ∫01​k​⋅4abksin3θcos3θdk

略做整理我们就可以得到
