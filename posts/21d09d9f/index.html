题目：设 z=f(x,y)z = f(x, y)z=f(x,y) 是区域 D={(x,y)∣0⩽x⩽1, 0⩽y⩽1}D = \{(x, y) \mid 0 \leqslant x \leqslant 1,\ 0 \leqslant y \leqslant 1\}D={(x,y)∣0⩽x⩽1, 0⩽y⩽1} 上的可微函数，f(0,0)=0f(0, 0) = 0f(0,0)=0，且

dz∣(0,0)=3 dx+2 dy\mathrm{d}z\big|_{(0,0)} = 3\,\mathrm{d}x + 2\,\mathrm{d}y dz​(0,0)​=3dx+2dy

求极限

lim⁡x→0+∫0x2dt∫xtf(t,u) du1−1−x44\lim_{x \to 0^+} \frac{\displaystyle\int_0^{x^2} \mathrm{d}t \int_x^{\sqrt{t}} f(t, u)\,\mathrm{d}u}{1 - \sqrt[4]{1 - x^4}} x→0+lim​1−41−x4​∫0x2​dt∫xt​​f(t,u)du​

这是一道求极限的题目，条件给的还算干净，虽然分子看起来很讨厌，但分母我们很熟悉，一下就可以等价成 x44\dfrac{x^4}{4}4x4​，那我们接下来就看看分子怎么处理。

换序

这个积分区域看起来很恶劣，那我们先交换一下积分次序看看。注意在这里 xxx 不是变量，可以看作一个常数。我们可以在一个以 ttt 为横坐标，uuu 为纵坐标的坐标系里，先画出 u=tu = \sqrt{t}u=t​ 这条曲线。注意到定义域在第一象限，我们在 uuu 轴上取定 u=xu = xu=x，画一条直线，可以发现这条直线和 u=tu = \sqrt{t}u=t​ 刚好交于 (x2,x)(x^2, x)(x2,x)，而 ttt 的积分范围就是 000 到 x2x^2x2，那么整个积分范围就是这个由 uuu 轴、u=xu = xu=x、u=tu = \sqrt{t}u=t​ 所围成的。那么我们很容易就能把它改写成

∫0x2dt∫xtf(t,u) du=−∫0xdu∫0u2f(t,u) dt\int_0^{x^2} \mathrm{d}t \int_x^{\sqrt{t}} f(t, u)\,\mathrm{d}u = -\int_0^x \mathrm{d}u \int_0^{u^2} f(t, u)\,\mathrm{d}t ∫0x2​dt∫xt​​f(t,u)du=−∫0x​du∫0u2​f(t,u)dt

洛必达

又有极限又有积分，这个积分长得就像是要用洛必达上下同时求导的样子。

lim⁡x→0+−∫0xdu∫0u2f(t,u) dtx44=lim⁡x→0+−∫0x2f(t,x) dtx3\lim_{x \to 0^+} \frac{-\displaystyle\int_0^x \mathrm{d}u \int_0^{u^2} f(t, u)\,\mathrm{d}t}{\dfrac{x^4}{4}} = \lim_{x \to 0^+} \frac{-\displaystyle\int_0^{x^2} f(t, x)\,\mathrm{d}t}{x^3} x→0+lim​4x4​−∫0x​du∫0u2​f(t,u)dt​=x→0+lim​x3−∫0x2​f(t,x)dt​

不错，看起来和蔼多了。不过看起来还能再洛一次，但是在处理之前，我们设想一下会发生什么，这个 fff 里面已经有 xxx 了，现在求导，一定会是一个较为复杂的式子，而且分子求导后仍会包含一项带有积分的式子 ∫0x2f2′(t,x) dt\displaystyle\int_0^{x^2} f'_2(t, x)\,\mathrm{d}t∫0x2​f2′​(t,x)dt，难以处理。那还有什么条件没用呢？哦，fff 在 DDD 上可微！可微就怎么样呢，那就一定在 DDD 上连续。看起来我们可以使用中值定理。

中值

lim⁡x→0+−∫0x2f(t,x) dtx3=−lim⁡x→0+f(ξ,x) (x2−0)x3=−lim⁡x→0+f(ξ,x)x,ξ∈(0,x2)\lim_{x \to 0^+} \frac{-\displaystyle\int_0^{x^2} f(t, x)\,\mathrm{d}t}{x^3} = -\lim_{x \to 0^+} \frac{f(\xi, x)\,(x^2 - 0)}{x^3} = -\lim_{x \to 0^+} \frac{f(\xi, x)}{x},\quad \xi \in (0, x^2) x→0+lim​x3−∫0x2​f(t,x)dt​=−x→0+lim​x3f(ξ,x)(x2−0)​=−x→0+lim​xf(ξ,x)​,ξ∈(0,x2)

由于 dz∣(0,0)=3 dx+2 dy\mathrm{d}z\big|_{(0,0)} = 3\,\mathrm{d}x + 2\,\mathrm{d}ydz​(0,0)​=3dx+2dy，那么 f1′(0,0)=3f'_1(0, 0) = 3f1′​(0,0)=3，f2′(0,0)=2f'_2(0, 0) = 2f2′​(0,0)=2，而 f(0,0)=0f(0, 0) = 0f(0,0)=0，那么

f(ξ,x)=f(0,0)+f1′(0,0) ξ+f2′(0,0) x+o(ξ2+x2)=3ξ+2x+o(ξ2+x2)f(\xi, x) = f(0, 0) + f'_1(0, 0)\,\xi + f'_2(0, 0)\,x + o\bigl(\sqrt{\xi^2 + x^2}\bigr) = 3\xi + 2x + o\bigl(\sqrt{\xi^2 + x^2}\bigr) f(ξ,x)=f(0,0)+f1′​(0,0)ξ+f2′​(0,0)x+o(ξ2+x2​)=3ξ+2x+o(ξ2+x2​)

对于 −lim⁡x→0+f(ξ,x)x-\displaystyle\lim_{x \to 0^+} \dfrac{f(\xi, x)}{x}−x→0+lim​xf(ξ,x)​，我们就要处理三个部分。由于 0<ξ<x20 < \xi < x^20<ξ<x2，即 0<ξx<x0 < \dfrac{\xi}{x} < x0<xξ​<x，x→0+x \to 0^+x→0+ 时，ξx→0+\dfrac{\xi}{x} \to 0^+xξ​→0+，即 lim⁡x→0+3ξx=0\displaystyle\lim_{x \to 0^+} \frac{3\xi}{x} = 0x→0+lim​x3ξ​=0。而 o(ξ2+x2)o\bigl(\sqrt{\xi^2 + x^2}\bigr)o(ξ2+x2​) 显然更是 xxx 的高阶无穷小，不放心的话我们算一下

lim⁡x→0+o(ξ2+x2)x=lim⁡x→0+o(ξ2+x2)ξ2+x2⋅ξ2+x2x=lim⁡x→0+o(ξ2+x2)ξ2+x2⋅1+(ξx)2=0\lim_{x \to 0^+} \frac{o\bigl(\sqrt{\xi^2 + x^2}\bigr)}{x} = \lim_{x \to 0^+} \frac{o\bigl(\sqrt{\xi^2 + x^2}\bigr)}{\sqrt{\xi^2 + x^2}} \cdot \frac{\sqrt{\xi^2 + x^2}}{x} = \lim_{x \to 0^+} \frac{o\bigl(\sqrt{\xi^2 + x^2}\bigr)}{\sqrt{\xi^2 + x^2}} \cdot \sqrt{1 + \left(\frac{\xi}{x}\right)^2} = 0 x→0+lim​xo(ξ2+x2​)​=x→0+lim​ξ2+x2​o(ξ2+x2​)​⋅xξ2+x2​​=x→0+lim​ξ2+x2​o(ξ2+x2​)​⋅1+(xξ​)2​=0
